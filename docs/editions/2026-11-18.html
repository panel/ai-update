The Saturation Point

GPT-6.2 arrived cheaper, more competent, and somehow a little dull — while the open web kept bleeding traffic and the coding-agent story quietly matured from “can it write the code” to “who on earth reviews it.”

The Big Picture

The headline event — GPT-6.2 Astra and Sol — is most interesting for what it doesn’t feel like. Astra dropped to 80% of its predecessor’s price (now $8/$40 per MTok, with cached input a brutal $0.40/million), Simon Willison notes, which is genuinely good news for long agentic sessions. But the reviews are muted. Every’s eval team called the models “careful, competent,” good for hands-off work with a clear format — and then admitted they were left “wanting more”. Latent Space’s framing is the sharpest: the #2 frontier model, 20–600% cheaper, mixed reviews. The tasks that were unsolved in January are now saturated. The frontier is flattening into a utility, and the thrill is migrating elsewhere.

Where it’s migrating is instructive. The most-upvoted stories of the period weren’t about capability at all — they were about consequences. AI answers cutting search traffic by 40% (677 points) and a careful, furious post titled AI is killing All About Berlin (734 points) say more about where we actually are than any benchmark. The open web’s economic model is quietly collapsing, and the labs are responding by buying their way around it — Le Figaro and LVMH Media both signed with OpenAI this week.

Meanwhile the coding-agent conversation grew up. The question is no longer whether agents can write code — they can, voluminously — but whether anyone can afford to review it. Harvard researchers found agents simply moved the bottleneck to code review, and curl’s Daniel Stenberg delivered the quote of the week on the limits of automated rewrites. Underneath both sits a security story that’s finally getting serious: sandboxing agent-executed code is becoming table stakes, with both Simon Willison and OpenAI shipping work on it the same week.

If there’s a through-line, it’s maturity over novelty. Cheaper models, review bottlenecks, sandbox patterns, web economics — this is the texture of a technology settling into infrastructure rather than announcing itself.

Themes

The frontier gets cheaper, and a little duller

The pattern across both OpenAI and Microsoft this period is price-performance, not capability-at-any-cost. GPT-6.2 Sol holds the line at $2/$10 and is positioned as the workhorse; Astra is cheaper and more careful than its predecessor but doesn’t display dramatically more judgment. Microsoft came to Ignite with seven new models tuned for scalable price-performance (339 points), and Satya Nadella declared himself AGI-pilled — but his version is about political economy, not superintelligence: who controls a model that could “become a health care company or take over the government.” The subtext is a positioning war against Anthropic, dressed up as philosophy.

The useful takeaway for your own work: the cached-input discount on Astra (10x cheaper than before) changes the arithmetic on long-running agent loops. Benchmark saturation means model choice is increasingly about cost, latency, and temperament rather than raw ceiling.

Coding agents hit the review wall

The most quotable rebuttal to “AI will just rewrite everything” came from curl’s Daniel Stenberg, via Simon Willison: while agents converted 185,000 lines of C into 340,000 lines of Rust, the actual curl project shipped 300 commits and 200 bugfixes those clones don’t have — “Will these clones keep up?” It’s a precise articulation of why vibe-porting produces a frozen snapshot, not a living project.

The structural version of the same point: Harvard researchers found that coding agents didn’t remove the bottleneck, they relocated it to code review (311 points, 421 comments — note the comment-to-point ratio, this touched a nerve). Generation is cheap; verification is the scarce resource now. Anthropic’s answer is to throw parallelism at it — Claude Code Projects now runs parallel workers — which arguably makes the review problem worse, not better. Worth watching whether tooling starts optimizing for reviewability rather than throughput.

Sandboxing agent code becomes table stakes

Two independent efforts landed the same week, which is usually how you know something’s real. Simon Willison introduced the external sandbox pattern — code runs inside a dedicated sandbox while the agent lives outside it — with three reference implementations (v86-in-WASM, Apple Containers, and QEMU via Microsoft’s Quicksand), all exposing the same localhost API so Claude Code, Codex, or Pi can target them. The motivating threat: prompt injection against local models taking damaging actions on your machine. On the same day, OpenAI published Inside the Codex sandbox, detailing filesystem and network enforcement across all three desktop OSes.

The threat is not hypothetical. Octopus, Gecko and Tortoise documents three scanners actively hunting exposed AI API keys by impersonating AI crawlers. If your agent setup doesn’t yet have a containment story, this is the quarter to build one.

The open web’s slow bleed

This is the period’s emotional center, and it’s an economic story more than a quality one. Google’s AI answers are reportedly cutting search traffic by ~40%, and a Berlin city-guide author documented in painful detail how AI is killing the business model of the independent reference site — the work gets scraped, summarized, and served without the click that paid for it. The labs’ response is bilateral deals with the big publishers who can command them: Le Figaro and LVMH’s media division both signed this week. The implicit message for everyone without a logo big enough to negotiate: adapt to “GEO” (generative engine optimization) or starve.

For developers this reframes a lot of assumptions — docs, tutorials, and reference content you’ve relied on being freely maintained now sit on an eroding base. Worth a thought about what happens to the long tail of technical knowledge when its funding model evaporates.

Own your model — and post-train it cheaply

Nadella’s “every company owns its own model” line is marketing, but the research under it is real and accelerating: the action has moved to cheap, targeted post-training of small models. DaisyRose-27B used 1,200 RL tasks to take Qwen3.8 from 5.6% to 12% on Terminal-Bench 4.1 — a reminder that domain RL now buys outsized gains on small bases. RepoFactory turns real repositories into 10,000+ verifiable training environments and reports +22.6 points on a repo-generation benchmark. And China’s TeleChat → Xing 4 (149 upvotes, the period’s top paper) pretrains a 285B model entirely on domestic Ascend silicon — a continuation of the decoupling story from the last edition, now with a full systems-engineering playbook attached.

The practical signal: if you have a narrow, verifiable task, the frontier API may no longer be the obvious default. The tooling to post-train a competent 27B on your own distribution is getting genuinely accessible.
